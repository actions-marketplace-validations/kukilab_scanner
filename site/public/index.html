Skills that scan you back? Fix them until they are SAFE.

KukiLab is a hybrid security scanner for AI agent skills — Claude Code, Codex, MCP. It strips hidden Unicode, checks the manifest and the code, reads the prose for prompt injection, and then does the part other scanners stop at: it repairs the skill and tells you exactly what to change.

Three passes, one verdict

No penalty for repository size. No false alarms on Cyrillic, German or Chinese documentation.

STEP 0 · SANITIZE

Active Unicode cleanup

Finds zero-width characters, BIDI overrides and stray byte-order marks in every text file, normalises to NFC and — with --fix — removes them in place.

STEP 1 · STATIC

Manifest and code

Validates SKILL.md, requires an explicit allowed-tools declaration, runs 25 code signatures and a Python AST pass for dynamic calls. Baselines keep verified false positives out of the verdict.

STEP 2 · SEMANTIC

The prose, read as data

Instruction override, hidden HTML comments, scope creep and exfiltration instructions in English, Russian or German — via Claude in CI, or by the host agent itself when KukiLab runs as a skill.

Three ways to run it

Pick the one that fits where the skill lives.

# clone, set up, scan
git clone https://github.com/kukilab/scanner.git && cd scanner
bash setup.sh && source venv/bin/activate
python src/kukilab_scanner.py /path/to/skill
# repair: remove hidden Unicode, add allowed-tools
python src/kukilab_scanner.py /path/to/skill --fix
# reports for CI and GitHub Security
python src/kukilab_scanner.py /path/to/skill --sarif results.sarif --json results.json
# .github/workflows/kukilab-scan.yml
- uses: kukilab/scanner@v1
  with:
    path: .
    fail-on: BLOCK                 # BLOCK | CAUTION | NEVER
    anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}   # optional
- uses: github/codeql-action/upload-sarif@v3
  with:
    sarif_file: kukilab.sarif
# install the skill into your agent
npx skills add kukilab/scanner --skill kukilab-scan
# then just ask:
"check this skill with kukilab and bring it to SAFE"
# Step 2 is done by the agent itself — no API keys, no external services
